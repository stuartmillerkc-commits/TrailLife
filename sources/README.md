# Source documents

Download these public-domain U.S. government publications into this folder before starting Phase 4. Claude Code cloud sessions may not have general internet access, so the PDFs need to be in the repo.

| File name to save as | What it is | Download from |
| --- | --- | --- |
| `cowpens-staff-ride.pdf` | John Moncure, *The Cowpens Staff Ride and Battlefield Tour*, Combat Studies Institute, 1996. Order of battle and timed maps 0700–0750. | https://www.govinfo.gov/content/pkg/GOVPUB-D110-PURL-LPS59122/pdf/GOVPUB-D110-PURL-LPS59122.pdf |
| `prices-expedition-atlas.pdf` | Charles D. Collins Jr., *Battlefield Atlas of Price's Missouri Expedition of 1864*, Combat Studies Institute, 2016. Covers Little Blue, Independence, Byram's Ford, Westport and Mine Creek. | https://www.armyupress.army.mil/Portals/7/educational-services/staff-rides/StaffRideHB_AtlasofPricesMissouriExpeditionof1864.pdf (mirror: https://apps.dtic.mil/sti/trecms/pdf/AD1112174.pdf) |
| `wilsons-creek-staff-ride.pdf` (optional) | *Wilson's Creek Staff Ride and Battlefield Tour*, Combat Studies Institute. Order of battle and timed maps 0500–1130. | https://apps.dtic.mil/sti/tr/pdf/ADA530378.pdf |

Pegasus Bridge has no equivalent staff ride guide; its facts come from the sources cited in `PLAN.md` section 8.4.
